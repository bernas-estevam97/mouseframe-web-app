The inked paw test, measured for you

Upload a scanned footprint sheet, mark each paw, and MouseFrame calculates stride length, stride width and overlap. No rulers, no spreadsheets of hand-typed numbers.

Open the analysis

  1. Upload

    Add a scanned or photographed footprint sheet. Any common image format works.

  2. Mark the paws

    Click each print: red for front paws, blue for hind paws, left and right.

  3. Export the results

    MouseFrame calculates every distance in pixels and centimetres. Copy the table or save it as an Excel file.
