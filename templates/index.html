What's new in version

  • Fixed visual bugs for PC resolutions.
  • MouseFrame is not a mobile app. Below a minimum screen width, the analysis page is replaced by a notice, while the other pages stay available.
  • Saved values can be reused without refreshing the app, so your progress on the current image is kept.
  • Each saved value stores the image size it was measured on, so the cm to pixel conversion is never applied to an image with a different resolution. Saving is not available for guest users.
  • Saved measurements are private to each user.
  • New image size toolbar above the image: type a size or use Fit, -, + and 100%. Picking a saved value measured on another size offers to resize the image to match.

Analysis

  • Points are drawn on a canvas placed over your image. You can add dots of different sizes and colours.
  • All tools appear after you upload an image.
  • See how each measurement is calculated on the information page.

Remove one point

  • Points appear in the list as you add them.
  • Select a point, then choose:
    • Remove deletes the point. The remaining points are renumbered as if it was never added.
    • Replace deletes the point and waits for one new point to take its place. Most buttons are disabled until you add it.

Remove a group of points

Instead of removing points one by one, you can remove a whole group: red left, red right, blue left or blue right. Click one of the buttons below.

Point size

The default radius is 4px.

A new size applies to the points you add next. Existing points keep their size.

Option 1: measure a 1 cm line

Recommended the first time you analyse a sheet.

  1. If the image includes a 1 cm line, click (or press Shift + M).
  2. Place two points at the ends of the line.
  3. Click (or press M) to measure the distance in pixels.
  4. The value appears under Result.

The eraser (D) or reset (R) removes the measurement points and the conversion value.

Option 2: enter or reuse a value

Only use a value measured on an image with the same dimensions as this one.

Type a known number of pixels in 1 cm, or pick a saved value. Use one of the two, then click Use.

Add entries

  • Calculates the distances between the points you marked.
  • Does not need the pixels-per-centimetre value. If it is set, values are also converted to cm. Use this when you only need distances in pixels.
  • Works with an incomplete set of points. An alert lists the measurements that could not be calculated.
  • Less strict than Add entries with average. Good when you only need some of the measurements.

Add entries with average

  • Calculates the complete set of measurements, converts them to cm and shows the mean of each measurement.
  • Needs the pixels-per-centimetre value first.
  • Needs every point marked in the correct place.
  • The most complete and strict way to collect the data.
