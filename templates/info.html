Purpose

MouseFrame automates the measurements traditionally taken by hand from mouse track sheets, which saves time and reduces human error.

A scanned sheet becomes an interactive canvas. You mark the paw prints on it, and the results can be exported to Excel or copied to the clipboard for further analysis.

Walking behaviour measurements

Front paws are marked in red and hind paws in blue. Every measurement is the Euclidean distance between two points on the image.

Front · left

Stride length, left front

Distance between consecutive left front prints, from L(x) to L(x+1). The last print in the sequence is excluded.

Hind · left

Stride length, left hind

Distance between consecutive left hind prints, from L(x) to L(x+1). The last print in the sequence is excluded.

Front · right

Stride length, right front

Distance between consecutive right front prints, from R(x) to R(x+1). The last print in the sequence is excluded.

Hind · right

Stride length, right hind

Distance between consecutive right hind prints, from R(x) to R(x+1). The last print in the sequence is excluded.

Front + hind · left

Overlap, left

Distance between the left front and left hind prints that share the same index.

Front + hind · right

Overlap, right

Distance between the right front and right hind prints that share the same index.

Front

Stride width, front

Distance between a front print and an intermediate reference point on the opposite side. See Figure 2.

Hind

Stride width, hind

Same method as the front stride width, using the hind prints. See Figure 3.

How stride width is calculated

You choose whether the first print in the sequence is left or right. The width is the distance between the selected print and an intermediate reference point I, which has the same x-coordinate as the selected print and the average y-coordinate of the two neighbouring prints on the other side.

I = ( L1x , (R1y + R2y) / 2 )

Marking order matters

Mark the prints in the order the animal walked. Footprints are processed in the order they were marked, so a different order gives incorrect measurements.

Each print must also be marked as the correct paw: front or hind, left or right.
