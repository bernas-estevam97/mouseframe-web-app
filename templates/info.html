How MouseFrame works

What the tool measures, and how each value is calculated from the points you mark.

Purpose

MouseFrame automates the measurements traditionally taken by hand from mouse track sheets, which saves time and reduces human error.

A scanned sheet becomes an interactive canvas. You mark the paw prints on it, and the results can be exported to Excel or copied to the clipboard for further analysis.

Walking behaviour measurements

Front paws are marked in red and hind paws in blue. MouseFrame calculates eight measurements:

  • Stride length left front
  • Stride length left hind
  • Stride length right front
  • Stride length right hind
  • Overlap left
  • Overlap right
  • Stride width front
  • Stride width hind

How the values are calculated

Every measurement is the Euclidean distance between two points on the image. The results depend on each print being marked as the right paw (front or hind, left or right).

Footprints are processed in the order they were marked, so keep that order consistent with the path of the animal. A different order gives incorrect measurements.

  • Stride length, left front. Distance between consecutive left front (red) prints, from L(x) to L(x+1). The last print in the sequence is excluded.
  • Stride length, left hind. Distance between consecutive left hind (blue) prints, from L(x) to L(x+1). The last print in the sequence is excluded.
  • Stride length, right front. Distance between consecutive right front (red) prints, from R(x) to R(x+1). The last print in the sequence is excluded.
  • Stride length, right hind. Distance between consecutive right hind (blue) prints, from R(x) to R(x+1). The last print in the sequence is excluded.
  • Overlap, left. Distance between the left front (red) and left hind (blue) prints that share the same index.
  • Overlap, right. Distance between the right front (red) and right hind (blue) prints that share the same index.
  • Stride width, front. Uses the front (red) prints. You choose whether the first print in the sequence is left or right. The width is the distance between the selected print and an intermediate reference point, which has the same x-coordinate as the selected print and the average y-coordinate of the corresponding left and right front prints.   • Stride width, hind. Uses the hind (blue) prints, with the same method as the front stride width. You choose whether the first print is left or right. See Figure 3.
